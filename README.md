# Jan & Coffee - Coffee Shop Website

## Topic
A multi-page responsive website for a coffee shop called **Jan & Coffee**, made by students of Astanait University.

## Pages
- `index.html` - Home (hero, welcome, features, popular drinks)
- `about.html` - About (story, team, journey, values)
- `menu.html` - Menu (price table, pastries, desserts)
- `gallery.html` - Gallery (photo grid with hover zoom and captions)
- `contact.html` - Contact (contact info, feedback form)

## Features
- Navigation bar on every page (Bootstrap navbar, collapses on mobile)
- Semantic HTML5: header, nav, main, section, article, figure, footer
- Table (menu prices) with header color, borders, alternate rows, highlighted row and colspan
- Form with text, email, select, radio buttons, textarea and submit button
- Flexbox: hero, drink cards, contact info boxes, footer
- CSS Grid: features block and photo gallery
- Positioning: caption overlay on gallery photos (relative + absolute)
- Media queries for tablet (992px) and mobile (576px)
- Bootstrap grid, buttons and spacing utilities
- Google Fonts: Playfair Display and Poppins
